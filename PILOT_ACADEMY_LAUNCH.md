# Памятка запуска первой академии

Цель: за 20–30 минут подготовить новую академию к пилотной работе без старых данных и путаницы с доступами.

## 1. Создание академии владельцем платформы

1. Открыть `/platform`.
2. Создать академию.
3. Заполнить страну, язык, валюту и часовой пояс.
4. Создать первого руководителя академии.
5. Открыть блок “Ссылки, логины и пароли”.
6. Скопировать готовое сообщение и отправить руководителю.

## 2. Первый вход руководителя

1. Руководитель открывает свою ссылку вида `https://lk2.sunnyfootball.com/<slug>/login`.
2. Вводит логин и временный пароль.
3. Открывает пункт меню “Первый запуск”.
4. Проверяет карточку готовности академии.

## 3. Минимальная настройка руководителем

1. Настройки → проверить название, страну, язык, валюту, контакты.
2. Пользователи → добавить администратора/тренера.
3. Группы → создать первые группы.
4. Ученики → добавить учеников и родителей.
5. Расписание → добавить тренировки.
6. Платежи → проверить абонементы/стоимость.

## 4. Кому что отправлять

### Руководителю академии

Отправляет владелец платформы из `/platform`:
- ссылка входа;
- логин;
- временный пароль;
- короткая инструкция открыть “Первый запуск”.

### Тренеру

Отправляет руководитель:
- ссылка входа академии;
- логин/пароль тренера;
- что тренер видит свои группы, расписание, посещаемость и сообщения.

### Родителю

Отправляет руководитель/администратор:
- ссылка входа академии;
- логин/пароль родителя;
- что родитель видит ребёнка, расписание, платежи и сообщения.

## 5. Контроль перед передачей клиенту

Новая академия должна быть пустая:
- история — 0;
- CRM/лиды — 0;
- маркетинг — 0;
- HR — 0;
- зарплаты — 0;
- чужих учеников/групп/платежей нет.
